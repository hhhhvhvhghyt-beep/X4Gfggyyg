پنل وایرگارد (واقعی)
=====================
این پنل خودش wg0 را بالا می‌آورد، NAT می‌زند، کاربر (peer) اضافه می‌کند
و بعد از اتمام حجم، کاربر را قطع می‌کند. بالای صفحه وضعیت وایرگارد و علت خطا نمایش داده می‌شود.

نیازمندی‌های سرور (شرط واقعی بودن):
  1) دسترسی NET_ADMIN و دستگاه /dev/net/tun
  2) پورت UDP 51820 از بیرون قابل دسترس باشد
  اگر CranL این دو را ندهد، بالای پنل «غیرفعال» با دلیلش را می‌بینید.

اجرا روی VPS:  docker compose up -d --build   (پورت پنل 8000)
اجرا روی CranL: ریپو GitHub > Build Type=Dockerfile > Port=8000
متغیرها: PANEL_PASSWORD, WG_ENDPOINT (مثلاً IP:51820), WG_PORT, WG_DNS
داده‌ها در پوشه data ذخیره می‌شوند (حتماً Volume دائمی بگذارید).
